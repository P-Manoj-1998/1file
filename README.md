# 1file

> One file is all you need.

Any topic. Any solution. Any snippet. Any learning.  
Everything lives entirely inside a single file—problem, explanation, and code all in one place.

---

### The Rule

- **One file for one thing:** Whatever the problem or topic is, the complete solution and context is inside that single file.
- **Self-contained:** No hunting for missing context or scattered files. You open one file, and you have everything you need.
- **Zero restrictions:** It can be a script, an automation, a deep dive, a quick fix, an email report, or a cheat sheet.
